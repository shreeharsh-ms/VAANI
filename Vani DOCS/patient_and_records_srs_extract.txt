4.9 CLINICAL RECORDS (CLN)
4.9.1 CLINICAL DATA ARCHITECTUREEncounter-centred model. Every clinical contact creates a visit (encounter). Assessments, session notes, plans and documents hang off the visit and the patient.Templates. Each assessment type has a typed schema (Section 5.5.20 to 5.5.34). The form UI is generated from a template definition so fields can be added without code changes (configurable fieldsstored in clinicalTemplates).Versioning. Clinical documents are versioned. Finalising (FINAL) makes the document read-only; edits after finalisation create a new version with a reason (addendum), retaining the old one.Signature. Finalisation records the clinician, timestamp, and optionally an e-signature image on the PDF.
